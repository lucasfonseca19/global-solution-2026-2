# Documentação do domínio

A raiz deste contexto é `global-solution-2026-2/`, não o workspace FIAP inteiro.

Antes de explorar ou especificar o projeto, ler:

- `CONTEXTO.md`, para decisões, restrições e dúvidas.
- `ENUNCIADO.md`, para obrigações da entrega.
- `GLOSSARY.md`, para vocabulário.
- ADRs relevantes em `docs/adr/`, quando existirem.

Usar um único glossário para este projeto. Criar ADRs somente para decisões difíceis de reverter, surpreendentes sem contexto e resultantes de alternativas reais. Decisões operacionais simples permanecem no mapa ou na especificação.

Não transformar sugestões do assistente em decisões do aluno. Atualizar os termos quando esclarecidos e apontar contradições com o enunciado ou decisões anteriores.

A falta de entrevistas não impede continuar a documentação; registrar a validação por pesquisa documental e os limites das hipóteses.
