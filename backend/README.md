# API e segurança

Pasta reservada para a API; sem implementação ou tecnologia escolhida pelo assistente.

O colega propõe C# com ASP.NET ou Java, respeitando o conteúdo até a fase 4, e revisa o [contrato proposto](../.scratch/merenda/api-contract.md).

Base funcional: login; listar, detalhar, criar, atualizar e excluir serviços; prévia de leitura com identificação por RFID, cálculo e validação sem gravação. A confirmação posterior grava a pesagem.

Obrigatórios: Controller, Service e Repository; validações e status HTTP adequados; documentação Swagger/Postman; senha em hash e pelo menos três práticas de segurança verificáveis. Não acrescentar CRUDs que não sejam necessários ao fluxo.

Referência: [especificação](../.scratch/merenda/spec.md). Acrescentar os comandos reais de execução e verificação após a implementação.
